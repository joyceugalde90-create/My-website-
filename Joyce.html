UEFI and BIOS

1. UEFI (Unified Extensible Firmware Interface)

UEFI stands for Unified Extensible Firmware Interface. It is a modern firmware interface that connects a computer's hardware to the operating system.

2. BIOS (Basic Input/Output System)

BIOS stands for Basic Input/Output System. It is firmware installed on the computer's motherboard. It starts the computer, checks the hardware, and prepares the system to load the operating system.

Functions of BIOS

  • Performs the Power-On Self-Test (POST).
  • Detects installed hardware devices.
  • Initializes system components.
  • Determines the boot device.
  • Loads the operating system.

3. Common BIOS Setup Keys

BIOS setup keys are pressed during computer startup to access BIOS or UEFI settings. The key depends on the computer's manufacturer.

  • F2
  • Delete
  • F10
  • Esc

4. Data Processing

Traditional BIOS uses a 16-bit environment, while UEFI supports 32-bit and 64-bit environments.

5. Advantages of UEFI

Large Disk Support

Supports drives larger than 2 TB when using GPT.

More Partitions

Allows more than four partitions when using GPT.

Faster Booting

Can help the computer start faster.

Better Security

Secure Boot helps prevent unauthorized boot software from loading.

Networking Features

Some UEFI systems support network booting and remote troubleshooting.

Graphical Interface

May provide a user-friendly setup menu that can be controlled using a mouse and keyboard.

Stable Initialization

Helps initialize hardware and verify boot components.

6. Example of Boot Order

The boot order determines which device the computer checks first when starting.

  1. USB Flash Drive
  2. SSD/HDD
  3. DVD Drive
  4. Network Boot

The boot order can be changed depending on the task, such as installing Windows from a USB drive.

12. Common BIOS Configuration Procedure

BIOS configuration allows users to check and change important computer startup settings.

  1. Enter BIOS setup.
  2. Verify the system date and time.
  3. Check CPU and memory detection.
  4. Verify storage devices.
  5. Enable or disable Secure Boot when necessary.
  6. Configure the boot mode (UEFI or Legacy).
  7. Set the USB drive as the first boot device when installing from USB.
  8. Save the changes and exit.

Windows Installation and Safety Precautions

1. Minimum Storage Requirement

Windows 10 version 1903 and later requires a minimum storage capacity of 32 GB.

Note: These are the commonly listed minimum requirements for Windows 10 version 1903 and later.

2. Safety Precautions Before Installing Windows

  • Back up important files before installation.
  • Ensure a stable power supply.
  • Disconnect unnecessary external devices.
  • Verify that the installation media is safe and free from malware.
  • Check compatibility with system requirements.
  • Do not interrupt the installation process.
  • Follow the proper shutdown procedure when restarting is necessary.

3. Minimum Hardware Requirements for Windows Server 2022

Windows Server 2022 requires specific hardware specifications to operate properly.

Component Minimum Requirement
CPU 1.4 GHz, 64-bit processor
RAM 512 MB for Server Core; 2 GB for Desktop Experience
Hard Disk Space 32 GB
Display Super VGA (1024 × 768) or higher
Network Ethernet adapter supporting at least 1 Gbps is recommended

Additional requirements may apply depending on the installation type and server configuration.

4. Firmware Requirements

  • UEFI 2.3.1c-based system and firmware that supports Secure Boot.
  • TPM 2.0 is required for certain security features, but not for every Windows Server 2022 installation.

7. Standalone OS vs. Network OS

Standalone Operating System (SOS) Network Operating System (NOS)
Manages one computer. Manages network resources and services.

Windows Server 2022

Windows Server 2022 is a server operating system developed by Microsoft that helps organizations manage network users, devices, applications, and data securely and efficiently.

It provides a platform for hosting services, managing users, sharing resources, and securing network operations.

1. Main Functions of Windows Server 2022

1. User and Account Management

  • Creates and manages user accounts.
  • Controls user permissions and access rights.

2. File and Printer Sharing

  • Allows users to access shared files and printers.
  • Provides centralized resource management.

3. Network Management

  • Manages network services and connected devices.
  • Supports communication between computers.

4. Security Management

  • Protects systems from unauthorized access.
  • Implements security policies and access controls.

5. Data Storage and Backup

  • Stores organizational data securely.
  • Supports backup and recovery operations.

6. Application Hosting

  • Runs web applications, databases, and network services.
